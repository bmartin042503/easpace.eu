Download macOS Apple Silicon 53.8 MB Download macOS Intel 56.1 MB

Signed and notarized by Apple. Open the .dmg file and drag easpace into Applications. macOS may ask for Keychain access, where easpace keeps its encryption key.

Before you install

  • This version needs Git to be installed. The next release removes this requirement. Download Git
  • easpace is still in development: you may run into bugs, and data loss can’t be ruled out, so keep backups of important data.

Tested on Windows 11 (x64 and ARM64) and on Macs with Apple Silicon. Linux, iOS and Android versions are planned.
